# Validators

This directory contains validation utilities for input validation and data integrity checks.

## Purpose

Centralized validation logic for:
- User input validation
- Data format validation
- Business rule validation

## Usage

Validators are used across the application to ensure data quality and user input correctness.

## Examples

- Email validation
- Text length validation
- Risk level validation
- File format validation

## Note

Validation logic is separated into dedicated validators to maintain clean code and reusability.
